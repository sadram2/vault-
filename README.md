# Vault

A collection of practical HashiCorp Vault implementations, configurations, experiments, and lessons learned.

This repository contains real-world examples and hands-on experiences with HashiCorp Vault, including authentication methods, secret management, Kubernetes integration, auto-unseal, and other operational scenarios.

## Contents

### Auto Unseal

Implementation and configuration of HashiCorp Vault Auto Unseal.

* [Vault Auto Unseal](./auto-unseal)

### Kubernetes

Integrating HashiCorp Vault with Kubernetes.

* Kubernetes authentication
* Service Account authentication
* Secret injection
* Vault policies and roles

### Authentication

Examples of different Vault authentication methods.

* Kubernetes Auth
* LDAP
* OIDC

### Secrets Management

Practical examples of managing and consuming secrets with Vault.

---

## Purpose

The purpose of this repository is to document practical experiences and lessons learned while working with HashiCorp Vault.

The examples are intended for learning, experimentation, and reference.

## Disclaimer

Secrets, credentials, tokens, private keys, and other sensitive information must never be committed to this repository.
